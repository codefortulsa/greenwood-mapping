# Project skills

Per-project Claude Code skills developed for greenwood-mapping live here.
Each skill is its own subdirectory with a `SKILL.md` describing when to
trigger it, followed by any scripts/templates it needs.

### Current

- **grill-me** — interview-style design stress-testing. Use when you want to be pushed to resolve every branch of a decision tree before implementing. Invoke via `/grill-me` or by asking to "grill me on X."
